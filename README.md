# Cognitive Systems
Reference materials by Kaitlin Sanders

Selected public-facing documentation from my work in cognitive systems: foundational principles, architectural design families, evaluation methodologies, applied evidence, and interpretation.

This collection introduces a larger body of ongoing development through materials selected for public sharing.

## Reference documents

| Document | What it covers |
|---|---|

| [Cognitive Integrity Evaluation (CIE)](<Cognitive_Integrity_Evaluation_CIE.pdf>) | A methodology for evaluating evidence use, reasoning, state integrity, adaptation, quality, and human and machine effort. |

## How the documents connect

**The Architecture of Executable Meaning** establishes the foundation. **Cognitive Design Families** shows how that foundation takes different architectural forms and how those forms relate.

**CIE** describes how cognitive integrity can be evaluated. The **Evolving Evidence Field** documents selected observations and reported findings, currently focused on agent applications of **Complex Analysis with Uncertainty & Field Dynamics**, supported by **Embodied Cognitive Composition**.

**From Signals to Meaning** brings related principles into enterprise interpretation, showing why context, relationships, and evidence status matter as information moves into human and AI workflows.

## Where to begin

Start with **Cognitive Design Families** for an overview. Explore **AEM** for the foundation, or read **CIE** alongside the **Evolving Evidence Field** to connect evaluation methodology with reported observations.

This collection will expand as additional materials and evidence become ready to share.
